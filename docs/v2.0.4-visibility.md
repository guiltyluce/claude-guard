# v2.0.4 可见性维护

## 目标

`v2.0.3` 已经能低噪声记录每个 Claude PID 的运行中网络状态，但使用者仍需手动
检索日志才能回答三个日常问题：当前有多少官方 Claude 会话、每个会话是否有
watchdog、最近一次异常是否已经恢复。

`v2.0.4` 将这些日志变成本地观察面，同时保持所有保护策略不变。它不实现 pause，
不修改请求，不调用模型，也不改变 Claude Code 的前台 TUI。

## Status

```bash
claude-guard status
claude-guard status --json
```

`status` 只读取：

- 安全配置中的原始 Claude 客户端路径、profile 和通知开关；
- 本机进程表；
- `guard.log.1` 与 `guard.log`。

它不会执行 curl，不检查实时出口，也不会启动 Claude。人类可读输出包含：

- `OK`：活动会话都有 watchdog，最近 PID 状态没有异常；
- `WARN`：至少一个活动会话缺少 watchdog，或最近状态是 degraded、recovering、
  would-pause、unknown 或 exited；
- `IDLE`：没有活动的官方 Claude 会话。

这里的健康值是本地快照，不是实时网络证明。`History` 明确表示历史事件，不能把
旧故障理解为当前故障。需要验证此刻网络时使用 `doctor`。

JSON 输出包含同样的信息，供本地小工具读取；它不承诺远程监控接口，也不会创建
后台服务。

## Doctor

```bash
claude-guard doctor
```

`doctor` 运行与启动官方 Claude 前相同的 8 步检查：配置和生命周期、项目与参数、
客户端身份和指纹、出口 IPv4、Anthropic API TLS、Claude 登录 TLS、IPv6 泄漏和
出口白名单。全部通过后追加 `status` 快照并退出。

它会访问 IP echo 与 Claude 官方域名，但不会启动 Claude Code，不会提交 prompt，
不会读取或使用 OAuth token，也不会消耗模型额度。

## Diagnose

```bash
claude-guard diagnose
```

`diagnose` 完全离线，输出版本、平台、模式、配置状态、活动会话数量、日志计数和
最近 20 条 watchdog / 链路事件。统计兼容旧版 `exit ip unknown` 和旧 sidecar 退出
文案；重复的 legacy-profile 启动警告不会挤占最近事件。输出会遮蔽：

- IPv4 地址；
- HOME 路径；
- `path=`、`profile=`、`command=` 后的绝对路径；
- 常见 `token=`、`key=`、`auth=`、`secret=` 赋值。

Guard 日志本身不应包含 prompt、response、OAuth token 或凭据。脱敏层是分享前的
第二道保护，不是允许日志记录秘密的理由。报告仍可能包含时间戳、PID、版本和事件
类型，分享前应按场景复核。

## 通知

安全配置可加入：

```json
{
  "notify": true
}
```

也可用 `CLAUDE_GUARD_NOTIFY=0|1` 临时覆盖。默认关闭。开启后只在 dry-run watchdog
发生 would-pause / would-resume 状态转换时调用 macOS `osascript`，持续故障不会按
5 秒 tick 重复通知。通知失败不会中断 Claude 或 watchdog。

## 不变边界

本版本保持：

- `CLAUDE_GUARD_WATCHDOG_DRY_RUN=1`；
- action mode 继续拒绝启动；
- 不发送 SIGSTOP、SIGCONT、SIGTERM 或 kill；
- 不改 endpoint、TLS、OAuth、profile、session 或 Claude 参数；
- 不改变 IP/API 探测频率与失败阈值；
- 不影响 `claude-cc` 或 CC Switch 通道；
- 已运行的 sidecar 不热更新，新版本只作用于之后启动的会话。

## 验证

`tests/visibility.sh` 使用 fake Claude、fake curl、临时进程树和保留地址验证：

- `status` 与 `diagnose` 零网络访问；
- 活动 Claude 和 watchdog 数量及 PID 状态；
- JSON 输出契约；
- 诊断报告不泄漏 fixture IP、路径或 secret；
- `doctor` 完成预检但不启动 Claude；
- 配置化通知只在 pause/resume 状态转换时各触发一次。

fixture 不读取真实配置、不连接互联网、不使用账号或模型额度。
